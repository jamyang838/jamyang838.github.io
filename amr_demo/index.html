運作原理

這顆虛擬感測器,怎麼做出來的

原料是場域既有攝影機,製程是全域 MOT。輸出一份資料:每個人的 Global ID + 連續世界座標軌跡 —— 下方八個展示,全部由這一份資料驅動。 身分連續,速度才準;速度準,流向、間隙、隊伍、群體才讀得懂。

單鏡頭 MOT 重疊區幾何接力 盲區時空拓撲 + Re-ID 世界座標投影 線上標定校正

  • 逐鏡頭偵測與追蹤

    各攝影機獨立執行多目標追蹤,取得短期軌跡片段。

  • 重疊區幾何接力

    投影至共用世界座標,以位置連續性判定為同一人。

  • 盲區身分接續

    以可行走拓撲與合理移動時間縮小候選,再以外觀特徵比對完成指派。

  • 連續全域軌跡

    輸出跨越盲區的長時連續軌跡與逐人速度,即時下發給機器人。
