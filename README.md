### AOD 雷射計算工具 [`/aod/`](https://jamyang838.github.io/aod/)

Angular 應用程式，用於計算 AOD（Acousto-Optic Deflector）相關雷射參數，包含：
- 雷射脈衝週期與數量
- AOD clock 延遲計算
- AOD 點數設定

Angular 原始碼位於 [`aod_angular/aod_ng/`](aod_angular/aod_ng/)。

---

### 雷射功率確認工具 [`/laserpower/`](https://jamyang838.github.io/laserpower/)

型號 M2R210 的雷射功率確認工具（PowerCheck），以 Angular + Bootstrap 5 + Firebase Authentication 建置。另有舊版保存於 [`/laserpower/legacy/`](https://jamyang838.github.io/laserpower/legacy/)。
