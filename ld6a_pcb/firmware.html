1. 韌體功能總覽

MCU 只負責「什麼時候出脈衝、電流設多少」，電流本身由類比迴路（Q1 + 積分器）調節；互鎖與脈寬上限是硬體，韌體不能蓋過。

功能韌體做什麼
脈衝時序LD_EN（RC5）每 1/F 拉高一次（內部觸發），或每個外部觸發拉高一次；高電位時間 = W + 補償。TMR1 定週期、TMR0 定脈寬，解析度 1 µs。
電流設定DAC_PWM（PWM5，31.25 kHz、10 bit）經濾波成脈衝設定值，滿刻度 6.56 A，每格約 6.41 mA。設定上限 6000 mA。
偏置電流BIAS_PWM（PWM6）設定脈衝之間的偏置 B（0–200 mA），讓 Q1 閘極停在臨界點，6 A 時邊沿才能 < 50 µs。
VPWR 伺服每一發在平頂量 Q1 的 Vds，每 10 ms 調 TRIM_PWM（CCP1），讓 buck 的 VPWR（2.4–4.0 V）剛好夠用，Vds 維持在目標 V（預設 600 mV），減少 Q1 發熱。
量測每發取樣兩次：電流 ISNS（每格 50 mA）與 LD 陰極電壓。板溫 NTC 每 100 ms 讀一次。統計最近 1 秒的實際脈衝數。
故障保護NO_CURRENT（LD 開路）、HEAT（Q1 過熱）、ILOCK（互鎖斷開）。任一發生立即停止輸出並鎖定。
人機介面SW1 短按解鎖／鎖定；長按切換電流檔。紅色 EMIT 燈顯示解鎖、檔位與故障碼。
USB 主控台經 FT230XS 的虛擬序列埠，9600 8N1。可設定全部參數、查詢狀態、存檔。不能解鎖，只有 SW1 能。
設定保存I、W、F、B、T、V 六項存在 EEPROM（含檢查碼），下次上電沿用；紀錄損壞就用預設值。

2. 脈衝參數與限制

參數意義範圍預設
I平頂電流。偏置在脈衝中的份量（1.947 × B）由韌體自動從 DAC 扣掉，平頂就是 I。50–6000 mA1000 mA
W電流半高寬（脈衝寬度）。實際 LD_EN = W + 補償。20–591 µs*500 µs
F重複率，週期 = 1/F（整數 Hz：例如 2.5 ms → F 400）。外部觸發時是觸發率上限。16–2000 Hz400 Hz
B脈衝之間的偏置電流。0 = 關閉（回到 rev A6 的死區，邊沿變慢）。0–200 mA50 mA
T觸發來源：INT 板上自振，EXT J6-1 外部觸發。INT / EXTINT
VQ1 Vds 伺服目標，一般不用改。300–1500 mV600 mV

* 指令本身接受 20–600，但 LD_EN 不能超過 600 µs，所以 B > 0 時 W 最大 591 µs；B = 0 時補償 = 339900 / I µs（1 A 時 339 µs），W 上限更小，而且 I < 586 mA 完全放不下。

四條硬限制（每個指令、SW1 和開機都要通過）

  1. I ≤ 6000 mA。
  2. LD_EN ≤ 600 µs（硬體另有約 1.2 ms 的脈寬限制，韌體當機也不會一直開著）。
  3. 工作週期 LD_EN × F ≤ 42 %（即 LD_EN [µs] × F [Hz] ≤ 420000）。
  4. I ≥ 2 × B。

超限的 W 或 F 直接拒絕，回應會給你最大可用值；改 I 或 B 造成超限時，韌體會把 W 縮到放得下並在回應中說明（見第 5 節）。

3. USB 主控台連線

J1（USB-C）只做通訊：FT230XS 由板上 5 V 供電，USB 不供電給板子，板子要先接 12 V。開關序列埠不會重置 MCU；燒錄器（J5）和 USB 可以同時插著。

項目設定
序列埠macOS：/dev/cu.usbserial-XXXX　Windows：COMx（裝置管理員查看）。兩者都是內建 FTDI 驅動。
格式9600 bps、8 資料位元、無同位、1 停止位元（8N1），無流量控制。
行尾CR 或 LF 都可以（CR LF 算一個行尾）。板子會回顯你打的字，Backspace / Delete 可刪字。
終端機程式macOS：screen /dev/cu.usbserial-XXXX 9600（離開：Ctrl-A、K、Y）或 CoolTerm。Windows：PuTTY、Tera Term。
# macOS：找序列埠並連線
ls /dev/cu.usbserial-*
screen /dev/cu.usbserial-XXXX 9600

上電時板子會印開機訊息（USB 要在上電前就插著才看得到）：

LD-PULSE-6A console, H for help
boot: I=1000mA W=500us F=400Hz B=50mA T=INT V=600mV LD_EN=509us (defaults, EEPROM blank)
一次一個指令。韌體在送出回應時不收字（接收緩衝只有 2 個字元），回應還沒印完就打下一行，那一行會遺失並回 ERR rx。等上一個回應出來再送下一個；用程式控制時尤其要注意（第 12 節）。

4. 指令一覽

指令範圍作用
I <mA>50–6000平頂電流。調高時 VPWR 伺服重新起步，回應加 (trim reset)。
W <us>20–600脈衝寬度（電流半高寬）。
F <Hz>16–2000重複率；外部觸發時是上限。
B <mA>0–200脈衝之間的偏置；0 = 關閉。
T INT / T EXT—觸發來源。T 和參數之間要有空白。
V <mV>300–1500Q1 Vds 伺服目標。
SAVE—把六項設定存進 EEPROM，下次上電沿用。
? 或 S—狀態（4 行，見第 6 節）。
H 或 HELP—指令說明（附錄）。
  • 語法：一行一個指令，大小寫不拘，十進位整數。數字前的空白可省（I500 = I 500），但 TINT 是未知指令。
  • 生效時機：指令收到就套用，解鎖中也一樣，新的電流與寬度從下一發開始。被拒絕的指令什麼都不改。
  • 不會自動存檔：主控台改的設定在斷電後消失，要保留請送 SAVE（SW1 長按則會自動存檔）。
  • 主控台沒有解鎖指令。可以先用 USB 設好參數，再按 SW1 開始出光。

5. 回應與錯誤訊息

成功回 OK 加上目前生效的全部設定；失敗回 ERR 加原因與可用上限。以下都是模擬器實際印出的文字：

I 3000
OK I=3000mA W=500us F=400Hz B=50mA T=INT V=600mV LD_EN=509us (trim reset)
F 800
OK I=3000mA W=500us F=800Hz B=50mA T=INT V=600mV LD_EN=509us
SAVE
OK saved, 13 bytes written
回應附註意思
(trim reset)電流調高，VPWR 回到 4.0 V 再由伺服往下調（約 1 秒內穩定），避免電壓不夠讓電流不足。
(W shrunk from 500us)新的 I 或 B 讓原本的 W 放不下，W 被縮小。之後改回去不會自動恢復，要自己再下 W。
OK saved, N bytes written只寫有變的位元組；N = 0 表示 EEPROM 已經是這組設定。
錯誤訊息（實例）原因與處理
ERR I range 50-6000 mA超出範圍（W、F、B、V 同格式）。
ERR F max 825Hz at LD_EN=509us (duty<=42%)工作週期超過 42 %；F 降到 825 以下，或先縮 W。
ERR W max 516us at 3000mA 800Hz (duty<=42%)同上，這次是 W 太寬。
ERR W max 591us at 3000mA (LD_EN<=600us)LD_EN 會超過 600 µs。
ERR B max 50mA at I=100mA (I>=2xB)偏置不能超過電流的一半。
ERR I min 400mA at B=200mA (I>=2xB)同上，先降 B 再降 I。
ERR I=400mA needs B>0 or I>=586mA (LD_EN<=600us)B = 0 時小電流的死區太長；把 B 開起來。
ERR未知指令或格式錯（例如 X 1、TINT、I 沒有數字）。
ERR rx接收錯誤：前一個回應還沒印完就打字、雜訊或鮑率錯。重送即可。

6. 狀態查詢 ?

回 4 行。以下是解鎖中、1 A 的示例（量測值為示意）：

armed=yes ilock=closed
I=1000mA W=500us F=400Hz B=50mA T=INT V=600mV LD_EN=509us
comp=9us dac=903mA duty=20.36% rate=400Hz preset=1 i_pulse=1000mA ld_k=720mV p_q1=142mW
bias=50mA trig=int vds_target=600mV vds_meas=700mV vpwr_trim=37 temp_C=41 fault=none
欄位意思
armedno 鎖定、arming 解鎖中但偏置還在建立（約 25 ms）、yes 出脈衝中。
ilock互鎖 J4：closed 可出光、open 硬體已切斷輸出。
第 2 行目前設定，與 OK 回應相同。
comp上升補償（B > 0 為 9 µs，B = 0 為 339900 / I）。
dacDAC 負責的電流 = I − 1.947 × B（其餘由偏置提供）。
duty設定的工作週期 LD_EN × F。
rate最近 1 秒實際發出的脈衝數（外部觸發時可用來確認觸發率）。
preset目前電流是哪一檔（1–4 = 1 / 2 / 4 / 6 A），不是預設檔位時顯示 -。
i_pulse實測平頂電流（每格 50 mA）。和 I 差很多就要查線或 LD。
ld_k實測 LD 陰極（Q1 汲極）電壓。
p_q1Q1 平均功耗估算（I × Vds × LD_EN × rate），超過 3 W 持續 5 秒會觸發 HEAT。
vds_target / vds_measVds 伺服目標 / 實測值。
vpwr_trimVPWR 調整量 0–1023：0 = 4.0 V（上限），1023 = 2.4 V（下限），每格 1.56 mV。
temp_CQ1 旁 NTC 的板溫。- 尚無讀值；n/a 感測器開路或短路。
faultnone 或目前的故障名稱（第 8 節）。

尚未量測時 ld_k、vds_meas 顯示 -。W < 約 55 µs 時脈衝太短，韌體來不及在平頂取樣：沒有 Vds 伺服、沒有 NO_CURRENT 偵測，VPWR 停在上次的值。

7. SW1、解鎖與指示燈

動作效果
短按（< 0.8 s）解鎖 ↔ 鎖定。解鎖時 ARM 立刻拉高、紅燈亮，偏置建立後才發第一發（B = 50 mA 時 25 ms）。
短按（有故障時）第一下只清除故障（印 SW1: fault cleared），再按一下才解鎖。
長按（≥ 0.8 s）電流跳到下一檔 1000 → 2000 → 4000 → 6000 → 1000 mA，立刻套用並存檔（解鎖中也會）。鎖定時紅燈閃 1–4 下表示檔位。主控台印 SW1: I=…。
  • 上電一律是鎖定狀態；上電時已經按著的按鍵要先放開才算數。
  • 互鎖開路或有故障時，按 SW1 不會解鎖。
  • 指示燈：綠 = 電源；紅（EMIT） = 解鎖／出光中，也用來閃檔位與故障碼；黃 = 互鎖閉合。
LD 安全。LZH 還沒確認測試用 LD 料號之前（10/20 寄來的是 3 W 料號，最大 3.5 A），電流不要超過 I 3000，也不要長按 SW1：從 2 A 長按一下就是 4 A，而且會存進 EEPROM。

8. 故障保護

任一故障：ARM 與 LD_EN 立刻拉低（鎖定）、紅燈重複閃故障碼（N 下、停 1.5 秒）、主控台印 FAULT …。只保留第一個故障，按 SW1 一下清除，再按一下才解鎖。主控台在等 UART 或 EEPROM 寫入時，這些檢查照樣執行。

閃故障條件
1NO_CURRENTI ≥ 500 mA 時，連續 8 發實測電流 < 20 % 設定值（LD 開路、線斷、驅動失效）。
2HEATQ1 功耗估算 > 3 W 持續 5 秒，或板溫 NTC 連續 3 次超過 85 °C（鎖定中也會檢查）。
3ILOCK解鎖中（或解鎖建立中）互鎖斷開。硬體本身已在微秒內切斷輸出，韌體再加一層鎖定。
FAULT NO_CURRENT (LD open / wiring / driver) i_pulse=0mA dac=5611mA - disarmed, press SW1 to clear
FAULT HEAT P_Q1=3120mW vds=1250mV - disarmed, press SW1 to clear
FAULT HEAT temp_C=85 - disarmed, press SW1 to clear
FAULT ILOCK - disarmed, press SW1 to clear
SW1: fault cleared
WARN ntc open (1023): 85 C guard off

WARN ntc open/short：NTC 開路或短路時只印一次，85 °C 那一半的保護關掉，P_Q1 估算那一半照常運作。

9. 外部觸發與 SYNC

  • T EXT 後，J6-1 每個上升緣發一發，寬度仍由 W 決定，延遲約 6 µs（最多約 12 µs）。輸入 3–24 V 正脈衝，高電位至少 5 µs（10 µs 最保險；更短的毛刺被濾掉），輸入電流 ≤ 10 mA。J6-2 = 地。
  • 一個邊緣只發一發；觸發維持高電位也只發一次。脈衝進行中的邊緣會被忽略。
  • F 是觸發率上限：要設得比觸發率高（例如觸發 400 Hz 就設 F 800）。工作週期 42 % 規則照樣適用。
  • 只在解鎖、互鎖閉合時才會出脈衝。? 的 rate 顯示實際收到的觸發率。
  • SYNC（J6-3）= LD_EN，5 V 邏輯直接來自 MCU，負載 ≥ 1 kΩ（示波器設 1 MΩ，不要接 50 Ω）。它標的是電子閘門，光比 SYNC 晚「補償」那麼久才出來。

10. 設定保存與開機

  • SAVE 或 SW1 長按會把 I、W、F、B、T、V 寫進 EEPROM（13 bytes，含檢查碼）。寫入約 13–65 ms，期間脈衝照常。
  • 開機時紀錄的 magic、檢查碼正確且通過全部限制才採用，否則一律用預設值，所以存檔不可能設出超限的值。開機訊息結尾說明來源：
開機訊息結尾意思
(saved)用 EEPROM 存的設定。
(defaults, EEPROM blank)EEPROM 是空的（剛燒完韌體）。
(defaults, rev A record ignored)舊版（rev A）格式，不採用。
(defaults, saved record invalid)檢查碼錯或值不合法。

重新燒錄韌體會清空 EEPROM（hex 不含 EEPROM 資料），燒完要重新設定並 SAVE。校準常數寫在 main.c，不受影響。

12. 用程式控制（Python）

需要自動化（掃參數、記錄 ?）時，用 pyserial（pip install pyserial）。每送一行就等到沒有新資料（0.5 秒）才送下一行，避免 ERR rx：

# ld6a_ctl.py — LD-PULSE-6A USB 主控台
import glob, serial

port = glob.glob("/dev/cu.usbserial-*")[0]     # Windows 改成 "COM5" 之類
ser = serial.Serial(port, 9600, timeout=0.5)

def cmd(line):
    """送一行指令，回傳板子的回應行（去掉回顯）。"""
    ser.write((line + "\r").encode())
    out = []
    while True:
        s = ser.readline()
        if not s:                # 0.5 s 沒有新資料 = 回應結束
            break
        out.append(s.decode(errors="replace").strip())
    out = [x for x in out if x and x != line]
    for x in out:
        if x.startswith("FAULT"):
            raise RuntimeError(x)
    return out

for c in ["I 3000", "W 500", "F 400"]:
    r = cmd(c)
    assert r and r[0].startswith("OK"), r
print("\n".join(cmd("?")))

程式只能改參數與讀狀態；出光仍要人按 SW1。FAULT 與 SW1: 開頭的行是板子主動送出的，隨時可能出現。

13. 編譯、燒錄與校準常數

cd ld6a/firmware
make                    # 編譯 main.c → ld_pulse6a.hex（不需要硬體）
make test               # host 測試（不需要硬體）
make program TOOL=ICD5  # 燒錄：ICD5 經 J5（PICkit 4 用預設 TOOL=PK4，SNAP 用 TOOL=SNAP）
  • USB 不能燒錄。板上沒有 bootloader，FT230XS 只接 UART，碰不到 MCLR。燒錄一定要經 J5（ICSP：1 VPP、2 VDD、3 GND、4 PGD、5 PGC），板子接 12 V，燒錄器不供電。
  • 每片板子的校準常數不同，寫在 main.c，改完重編、各存成 ld_pulse6a_SNxx.hex：ISET_CAL_DEN、BIAS_CAL_DEN、BIAS_PULSE_NUM、RISE_COMP、DEADZONE_CAL、ADC_FVR_MV、VDS_DIV_X1000。量測方法見 firmware/NOTES.md §5。
  • 電流上限 I_MAX_MA（6000）與 SW1 檔位 PRESET_TABLE_MA（1/2/4/6 A）是編譯期常數，主控台改不了。
